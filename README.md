# 🚗 Projet Covoiturage Universitaire – POO en Java

## 🎯 Objectif du projet

Le but de ce projet est de **concevoir une application de covoiturage universitaire** en utilisant la **programmation orientée objet (POO)** en Java. L'application est spécifiquement dédiée à la **communauté universitaire de Bab Ezzouar** (étudiants, enseignants, personnel ATS).

---

## 🧩 Objectifs pédagogiques

- ✔️ Appliquer les concepts de **modélisation objet** : classes, héritage, encapsulation, etc.
- ✔️ Respecter les **principes de conception logicielle** : modularité, réutilisabilité.
- ✔️ Développer une application **fonctionnelle en Java** (sans base de données, ni interface graphique).
- ✔️ Travailler **en équipe** avec une répartition claire des tâches et une documentation rigoureuse.

## 🗂️ Structure du rapport

1. **Introduction**
   - Objectif de l’application
   - Contexte et enjeux
2. **Modélisation**
   - Diagramme UML
   - Justification des choix de classes et d’héritage
3. **Descriptions des classes**
   - Attributs, méthodes, encapsulation
4. **Répartition des tâches**
   - Qui a fait quoi
5. **Conclusion**
   - Difficultés rencontrées
   - Idées d’amélioration

## 👥 Répartition des tâches

| Membre   | Tâches principales |
|----------|--------------------|
| **Asma**    | Implémentation de `Course`, gestion des courses et matching + la classe main |
| **Manar**   | Modélisation UML, classes Utilisateur, Etudiant, Enseignant, ATS |
| **Imene**   | Gestion du profil, itinéraires, préférences, disponibilités |
| **Raghad**  | Évaluations, statistiques, administration et réputation |
